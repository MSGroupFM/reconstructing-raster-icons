# v0.1.0 release notes

Status: local `v0.1.0` release tag dated 2026-08-28. Remote publication
readiness is **BLOCKED** until the exact tagged commit completes the full
post-push CI workflow. No package upload, pushed tag, or public release is
claimed.

## Scope

`v0.1.0` reconstructs monochrome raster icons as editable SVG and evaluates
them under acceptance model `1.0.3`. Meaningful multicolor, gradients,
intentional translucency, photographs, and painterly images require a declared
analysis/user scope decision and are not silently accepted. The deterministic
CLI enforces that declaration and confirmation; it does not perform automatic
semantic color detection.

## Included capabilities

- mandatory confirmation of the accuracy target before writes;
- mandatory same-source VTracer black-and-white spline sweep, recorded trace
  provenance, and evidence-based full/component candidate selection;
- one frozen cleaned grayscale trace master with retained antialiased edge
  coverage; binary reference and diagnostic masks never become VTracer input;
- postprocessing limited to evidenced circles, ellipses, and straight
  segments, with no manual organic-path reconstruction or tracer fallback;
- default `1:1` viewport, centered `contain`, grid maximum side `64`, and
  confirmed standard/custom ratio handling through `1:16..16:1`;
- frozen reconstruction-map revisions, masks, normalization decisions,
  component IDs, constraints, and SHA-256 artifact inventory;
- safe raster decoding and allowlisted SVG parsing before render;
- hash-pinned Node `22.14.0` and `@resvg/resvg-wasm@2.6.2` rendering contract;
- a `15 s` parent wall timeout, `512 MiB` V8 old-space limit, and child-attested
  `--disable-wasm-trap-handler`; these controls do not claim a hard RSS,
  total-memory, or virtual-address-space ceiling;
- unrounded `S/C/L/T` calculations and composite score, independent blocking
  gates, and schema-valid machine reports;
- baseline plus eight refinements by default, with the exact three-refinement
  stall rule and no automatic target/tolerance reduction;
- independent final-SVG renders at exactly 128, 64, 32, and 24 px, with no
  downscaling from a raster master for target-size review;
- original synthetic conformance and adversarial corpus;
- portable corpus `1.0.1` verification under PNG sub-contract `1.0.0`:
  same-host builds remain raw-byte exact for every generated file, while
  cross-platform PNG comparison ignores only IDAT compression bytes/boundaries
  and keeps pixels plus metadata exact;
- versioned exact generated-file inventory, bounded single-stream IDAT
  validation with strict IHDR/Adam7-derived filtered length (but no
  cross-platform filtered-byte comparison), and duplicate-rejecting type-aware
  relational draft comparison;
- repository-local validation, SHA-pinned GitHub Actions workflow, hashed
  Python lock, and deterministic ZIP/checksum builder.
- cross-platform renderer attestation aligned with the actual Node `22.14.0`
  filesystem, child-process, and worker permission scopes; network denial is
  not falsely claimed, while the runner has no network import, passes the
  loader already-read WASM bytes, and candidates cannot contain external
  resources.
- real phone and strategy-board visual examples showing prior reconstruction
  attempts beside the VTracer workflow output.

## Release artifacts to build

```text
reconstructing-raster-icons-v0.1.0.zip
reconstructing-raster-icons-v0.1.0.zip.sha256
```

The ZIP contains source, schemas, reusable fixtures/tests, skill references,
and public documentation. It excludes Git metadata, installed dependencies,
caches, symlinks, run diagnostics, and `tests/behavioral/evidence/`. The latter
is committed development evidence that mixes summaries with verbatim runs and
local harness provenance; reusable behavioral scenario prompts remain.
The portable PNG fixture rule does not apply to release archives: two builds of
the ZIP and checksum remain required to be byte-identical.
