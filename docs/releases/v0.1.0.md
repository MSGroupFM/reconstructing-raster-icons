# v0.1.0 release notes

Status: local release candidate prepared on 2026-08-26. Publication readiness
is **BLOCKED** pending the mandatory live Ubuntu x64 canonical zero-skip CI
run. No GitHub remote, tag, push, package upload, or public release is claimed.

## Scope

`v0.1.0` reconstructs monochrome raster icons as editable SVG and evaluates
them under acceptance model `1.0.0`. Meaningful multicolor, gradients,
intentional translucency, photographs, and painterly images require an
explicit scope decision and are not silently accepted.

## Included capabilities

- mandatory confirmation of the accuracy target before writes;
- default `1:1` viewport, centered `contain`, grid maximum side `64`, and
  confirmed standard/custom ratio handling through `1:16..16:1`;
- frozen reconstruction-map revisions, masks, normalization decisions,
  component IDs, constraints, and SHA-256 artifact inventory;
- safe raster decoding and allowlisted SVG parsing before render;
- hash-pinned Node `22.14.0` and `@resvg/resvg-wasm@2.6.2` rendering contract;
- unrounded `S/C/L/T` calculations and composite score, independent blocking
  gates, and schema-valid machine reports;
- baseline plus eight refinements by default, with the exact three-refinement
  stall rule and no automatic target/tolerance reduction;
- original synthetic conformance and adversarial corpus;
- repository-local validation, SHA-pinned GitHub Actions workflow, hashed
  Python lock, and deterministic ZIP/checksum builder.

## Release artifacts to build


caches, symlinks, run diagnostics, and `tests/behavioral/evidence/`. The latter

local harness provenance; reusable behavioral scenario prompts remain.
